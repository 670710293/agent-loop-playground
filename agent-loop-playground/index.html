Agent เก่งกว่า chatbot ตรงไหน?

chatbot ตอบทีเดียวจากสิ่งที่จำได้ ส่วน agent จะวนลูปคิด ลงมือ แล้วดูผล จนกว่างานจะเสร็จ เลือกโจทย์แล้วกดรันเพื่อดูเทียบกัน

Chatbot

ตอบครั้งเดียว ไม่มีเครื่องมือ

Agent

วนลูปจนงานเสร็จ ใช้เครื่องมือได้

    ลูปของ agent มี 4 ส่วน

    คิด
    โมเดลประเมินเป้าหมายและตัดสินใจว่าขั้นต่อไปควรทำอะไร
    เรียกเครื่องมือ
    สั่งใช้ฟังก์ชันภายนอก เช่น ค้นเว็บ ดูสภาพอากาศ หรือเครื่องคิดเลข
    ดูผลลัพธ์
    ข้อมูลที่ได้กลับมาถูกส่งเข้าบริบท เพื่อใช้ตัดสินใจรอบถัดไป
    ตอบ
    เมื่อมีข้อมูลพอ agent หยุดลูปและสรุปคำตอบให้ผู้ใช้

    หน้านี้เป็นการจำลองด้วยข้อมูลสคริปต์ ไม่ได้เรียกโมเดลจริง ดู README สำหรับวิธีต่อกับ LLM API
