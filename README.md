เว็บที่ให้ผู้ใช้พิมพ์หัวข้อที่อยากเรียน แล้วดู AI agent ค้นคว้า ประมวลผล และทำ **ชีทสรุปพร้อมแหล่งอ้างอิง** ทีละขั้น
ทำขึ้นเป็นโจทย์ก่อนสัมภาษณ์ **YWC 21** (สาย Web Programming) โฟกัสหมวด "การเรียน" หมวดเดียว

- **Live:** _ใส่ URL หลัง deploy_
- **Tech stack:** HTML, CSS, JavaScript (ไม่มี build step), Wikipedia API, GitHub Pages

## agent ตัวนี้ทำงานยังไง (พูดตามจริง)
เป็น agent แบบ **rule-based** ไม่ใช่ LLM: โค้ดตัดสินใจลำดับขั้นเอง แต่เครื่องมือค้นคว้าเป็นของจริง
ลูปคือ ค้น → เลือกผลลัพธ์ → อ่านเนื้อหา → ประมวลผล → ตอบ ถ้าไม่พบภาษาไทยจะลองภาษาอังกฤษ
ข้อจำกัด: ใช้ Wikipedia แหล่งเดียว, สรุปแบบเลือกประโยคเดิม (extractive) ไม่ได้เรียบเรียงใหม่, ยังไม่ได้ตรวจความถูกต้อง

## รันในเครื่อง
```bash
python3 -m http.server 8000   # เปิด http://localhost:8000
```
Deploy: GitHub Pages (Settings → Pages → branch `main` / root) ไฟล์ต้องอยู่ที่ root ของ repo

## แผนต่อยอด
1. เพิ่ม `api/summarize.js` (Vercel serverless) เก็บ API key ฝั่งเซิร์ฟเวอร์ แล้วเพิ่ม `TOOLS.llm_summarize`
2. ค้นหลายแหล่งและจัดอันดับความน่าเชื่อถือ
3. ใช้ prompt ใน Catalog ทำแฟลชการ์ดและข้อสอบ
4. เก็บประวัติการค้นของผู้ใช้
