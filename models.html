02 / สำรวจโมเดลเฉพาะทาง

เลือกโมเดลให้เหมาะ
กับงานที่ต้องทำ

สำรวจโมเดลที่ออกแบบมาสำหรับงานเฉพาะด้าน ตั้งแต่เขียนโค้ด สร้างภาพ ประมวลผลเสียง ไปจนถึงค้นคว้าและอ่านเอกสาร

6 หมวดเฉพาะทางสูงสุด 3 โมเดล / หมวดเน้นเลือกตามลักษณะงาน
อ่านก่อนเลือก

รายการนี้เน้นโมเดลและตระกูลโมเดลที่มีความเชี่ยวชาญเฉพาะด้าน ไม่ใช่อันดับความเก่งหรือการรับรองว่าเป็นตัวเลือกที่ดีที่สุด โมเดลบางตัวเป็นบริการ API หรือเครื่องมือที่มีโมเดลอยู่เบื้องหลัง ควรตรวจชื่อรุ่น ความสามารถ License และเงื่อนไขการเข้าถึงจากเอกสารทางการก่อนใช้งาน
