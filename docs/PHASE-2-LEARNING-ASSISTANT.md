# Phase 2 — Learning Assistant

## สิ่งที่ปรับปรุง
- ปรับพื้นที่ป้อนคำถามและตัวอย่างคำถาม โดยรักษาการทำงานเดิม
- คงบทบาท Agent 5 ตัว: Planner, Researcher, Analyst, Writer และ Reviewer
- เพิ่มป้ายระบุชัดเจนว่าเป็น Rule-based Workflow
- ปรับข้อความแสดงขั้นตอนและสถานะการทำงาน
- เพิ่มทางเลือกค้นหา Wikipedia ภาษาไทย/อังกฤษ
- เพิ่มการจัดการ API Error, ไม่มีบทนำบทความ และเนื้อหาสั้นเกินไป
- คงชีทสรุป ลิงก์แหล่งข้อมูล ปุ่ม Copy Markdown และ Download Markdown
- ระบุชัดว่าการวิเคราะห์และการตรวจสอบเป็น Logic JavaScript ที่ให้ผลตามกฎ

## พฤติกรรมที่เกิดขึ้นจริง
- Researcher: ส่งคำขอไปยัง Wikipedia API จริง
- Analyst: วิเคราะห์ด้วยการแบ่งข้อความและนับความถี่คำใน Browser
- Writer: ประกอบเนื้อหาเป็น Markdown ตาม Template
- Reviewer: ตรวจโครงสร้างพื้นฐาน เช่น จำนวนประเด็น คำสำคัญ และ URL แบบ HTTPS

## ข้อจำกัด
Reviewer ไม่ได้ตรวจว่าข้อความถูกต้องตามข้อเท็จจริงหรือไม่ ชีทสรุปเลือกประโยคจากแหล่งข้อมูลมาจัดรูปแบบ ไม่ใช่การสรุปแบบ Generative ด้วย LLM

## การปรับปรุง v8.1: ตรวจความตรงกับคำถาม
1. ผู้ใช้เลือกภาษาไทย, English หรือ Auto detect
2. Planner เก็บคำถามต้นฉบับและเตรียมคำค้น
3. Researcher ค้นหลายคำค้น รวมผลไม่ซ้ำ และข้ามบทความที่เคยลอง
4. Analyst เลือกประโยคโดยให้น้ำหนักคำที่มาจากคำถาม
5. Writer สร้างร่างในภาษาที่เลือก
6. Reviewer ตรวจความเกี่ยวข้องของทั้งบทความและประเด็นสรุป หากไม่ผ่านจะส่งกลับ Researcher เพื่อใช้แหล่งใหม่
7. หากไม่มีแหล่งใดผ่าน จะไม่แสดงชีทสรุปที่ไม่ผ่าน

หมายเหตุ: Reviewer เป็น heuristic จากการจับคู่คำ ไม่ใช่ LLM semantic evaluator จึงไม่รับประกันความเข้าใจความหมายหรือความถูกต้องทุกประโยค


## Update v8.3
- นำตัวเลือกภาษาออกจากหน้าเว็บ ผู้ใช้พิมพ์ไทยหรืออังกฤษได้โดยไม่ต้องตั้งค่า
- Researcher พยายามสร้างคำค้นอีกภาษาผ่าน MyMemory และค้น Wikipedia/ DuckDuckGo Instant Answer ทั้งไทยและอังกฤษ
- Writer แปลหลักฐานภาษาอังกฤษเป็นไทย รวมประเด็นจากหลายแหล่ง ตัดซ้ำ และเรียงคำอธิบายก่อนเหตุผล/กลไกและผลลัพธ์
- เอา Keyword cloud ออก; Self-review ยึดคำถามต้นฉบับและการอ้างหลักฐาน ไม่สุ่มจากคำที่พบบ่อย
- เพิ่ม timeout และ error handling เพื่อให้ผู้ใช้ได้รับข้อความเมื่อ API ไม่ตอบ และปุ่มส่งกลับมาใช้งานได้
- ข้อจำกัด: Translation API อาจไม่พร้อมใช้งาน; Reviewer ยังไม่เข้าใจความหมายหรือ fact-check แบบ LLM
