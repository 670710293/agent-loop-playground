# Phase 4 — Model Explorer

## Implemented
- Added six categories on one page:
  1. Learning & Research
  2. General Chat
  3. Coding & Development
  4. Data Analysis
  5. Long Context & Documents
  6. Creative & Multimodal
- Each category contains two or three curated model families.
- Cards show provider, general fit, strengths, caveat, and official documentation link.
- Category navigation uses in-page anchors.
- Avoided price tables, universal rankings, and unverified benchmark scores.

## Data policy
Entries are model families, not a guarantee about every model/version in that family. Capabilities vary by specific model and product. Users are directed to official documentation to verify current details.
